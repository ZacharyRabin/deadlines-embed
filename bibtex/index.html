Notion field order and formulas
Each paper is one line, fields joined by ¤ and line breaks inside a field written as ¶.
Name ¤ Authors ¤ Conference ¤ Year ¤ Link ¤ Abstract ¤ BibTeX

In Notion, with the pasted line in a text property called Paste:
  Name        prop("Paste").split("¤").at(0)
  Authors     prop("Paste").split("¤").at(1)
  Conference  prop("Paste").split("¤").at(2)
  Year        toNumber(prop("Paste").split("¤").at(3))
  Link        prop("Paste").split("¤").at(4)
  Abstract    prop("Paste").split("¤").at(5)
  BibTeX      prop("Paste").split("¤").at(6).replaceAll("¶", "\n")

The Conference value is the short label your Papers database already uses (CVPR, NeurIPS, TPAMI, "arXiv preprint"), whatever the venue-name toggle says.
